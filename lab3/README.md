Шаблонный `Vector<T>` самостоятельно управляет памятью. `unique()` сохраняет первые вхождения без дубликатов. `partition(pivot)` перемещает значения меньше порога влево и возвращает индекс начала правой части. Итераторы поддерживают обход и алгоритмы STL.

## Сборка и запуск

```sh
clang++ -std=c++17 -O2 -Wall -Wextra -Wpedantic main.cpp -o lab3
./lab3
```

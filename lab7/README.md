# Лабораторная работа № 7

Быстрая сортировка, сортировка слиянием, пирамидальная сортировка

- Дисциплина: Алгоритмы и структуры данных

- Вариант 10
- [Полный отчёт в Word](лабораторная7аисд.docx)

Вариант 10, продвинутый уровень. Quick Sort с медианой трёх и трёхчастным разбиением, устойчивый Merge Sort и Heap Sort с итеративным просеиванием.

Программа строит [визуализацию шагов](steps.svg) и [график замеров](timing.svg). Замеры берутся с одинаковых случайных массивов, медиана девяти запусков для каждого размера.

## Сборка и запуск

```sh
clang++ -std=c++17 -O2 -Wall -Wextra -Wpedantic main.cpp -o lab7
./lab7
```

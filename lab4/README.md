# Лабораторная работа № 4

Односвязный и двусвязный списки

- Дисциплина: Алгоритмы и структуры данных
- Студент: Осипов Герман Юрьевич, ПИЖ-б-о-25-2
- Вариант 10, продвинутый уровень
- [Полный отчёт в Word](Отчёт_Осипов.docx)

Шаблонные `SinglyLinkedList<T>` и `DoublyLinkedList<T>` поддерживают основные операции со списками. Вариант 10 включает очистку с выводом размера, удаление каждого второго узла и обратный обход через `reverse_iterator`.

## Сборка и запуск

```sh
clang++ -std=c++17 -O2 -Wall -Wextra -Wpedantic main.cpp -o lab4
./lab4
```
